# ขอบเขตโครงการฉบับปรับให้ลงมือทำและตรวจสอบได้

สร้างต้นแบบ Smart Waste Detective สำหรับ IT232 โดยใช้ Python 3.11, Streamlit, CLIP, SQLite และ Plotly เป้าหมายคือรับภาพวัตถุหนึ่งชิ้น เสนอประเภท Plastic Paper Glass Hazardous หรือ Unknown แสดงคำแนะนำ และเก็บประวัติการวิเคราะห์

ใช้ CLIP pretrained และ prompt ensemble เฉพาะทางเป็น customization รุ่นแรก บันทึก prompts, รุ่นโมเดล, threshold และคะแนนจริงทุกครั้ง ห้ามเรียกวิธีนี้ว่า fine-tuning และห้ามสร้างผลสำรองปลอมเมื่อโมเดลผิดพลาด

ข้อมูล Dashboard ต้องอ่านจาก SQLite และใช้ชื่อ metric เป็นครั้งที่วิเคราะห์ แยกรายการทดสอบออกจากสถิติทั่วไป ห้ามนำตัวเลขนี้ไปอ้างจำนวนชิ้น น้ำหนัก คาร์บอน หรือปริมาณรีไซเคิลจริง

ทดสอบทั้งฟังก์ชันและโมเดล โดยแยกผลออกจากกัน เก็บ manifest แหล่งภาพ สิทธิ์ label และ split ใช้ชุดตัวอย่าง 50 ภาพเพื่อวินิจฉัยเบื้องต้นเท่านั้น แสดงผลรายประเภทและทุกกรณีผิด ข้อมูล validation/test หน้างานและ user feedback เป็นงานถัดไปที่ยังต้องทำจริง

ผลส่งงานประกอบด้วย Proposal Word/PDF Workflow และ Architecture PNG/SVG เว็บที่รันในเครื่องได้ tests และหลักฐาน สไลด์ PowerPoint 12 หน้า บทพูด 10/5 นาที คู่มือ และ ZIP เว้นชื่อสมาชิกให้กรอกภายหลัง ทุกเอกสารอธิบายสถานะปัจจุบัน ข้อจำกัด และขั้นตอนที่กลุ่มต้องทดลองต่ออย่างตรงไปตรงมา
