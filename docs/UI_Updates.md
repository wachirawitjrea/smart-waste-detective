# ปรับหน้าแรกตามคอมเมนต์การออกแบบ

- ย่อแบนเนอร์เป็นแถบแนวนอน สูงประมาณ 110 px บนหน้าจอเดสก์ท็อป พร้อมปุ่มเริ่มวิเคราะห์ภายในแถบ
- ลบข้อความมหาวิทยาลัย โครงการ และรายละเอียดการประมวลผลที่อยู่ใต้เมนู Sidebar
- จัดสถิติและประเภทขยะเป็นเนื้อหาหลัก ใช้การ์ดสูงเท่ากัน ไอคอนเส้น และสีประจำประเภท
- เก็บขั้นตอนการใช้งานสามขั้น ปรับเป็นการ์ดพร้อมหมายเลข และเรียงลงบนมือถือ
- ลบกล่องข้อความแจ้งเตือนท้ายหน้าแรกตามคอมเมนต์

คำอธิบายโมเดลและข้อจำกัดยังอ่านได้ในหน้าวิเคราะห์

ตรวจเว็บจริงที่ความกว้าง 1100 px และ 390 px ไม่พบเนื้อหาล้นแนวนอน ปุ่มเริ่มวิเคราะห์เปิดหน้ารับภาพได้ ตรวจการเปิดครบทุกหน้าด้วย AppTest ผ่าน

ภาพหน้าจอหลังปรับอยู่ที่ `assets/screenshots/home_updated_desktop.png` และ `home_updated_mobile.png` ภาพใน Proposal ฉบับเดิมเป็นภาพจริงจากรุ่นก่อนปรับหน้าแรก

## ปุ่มเริ่มวิเคราะห์แบบ Liquid Glass

ลบข้อความแนะนำในแบนเนอร์ออกตามคอมเมนต์ล่าสุด และขยายปุ่มให้เต็มพื้นที่แถบด้านบน ขนาดประมาณ 734 × 96 px ที่ viewport กว้าง 1100 px และเต็มความกว้างพื้นที่บนมือถือ ใช้พื้นผิวกระจกโปร่งแสงสีเขียว ขอบสะท้อนแสง และเงา ปุ่มยกตัวเมื่อชี้เมาส์ ยุบตัวเมื่อกด และมีแสงพาดผ่านเป็นระยะ พร้อมกรอบ focus สำหรับคีย์บอร์ด

ตรวจ hover และ press จากเบราว์เซอร์จริงแล้ว ปุ่มยังเปิดหน้าวิเคราะห์ผ่าน callback เดิม เมื่อระบบตั้งค่า prefers-reduced-motion แอนิเมชันและ transition จะหยุด ตรวจมือถือ 390 px ไม่พบเนื้อหาล้นแนวนอน

ภาพล่าสุดคือ `assets/screenshots/home_liquid_glass.png`, `home_liquid_glass_hover.png` และ `home_liquid_glass_mobile.png`

## ลบหน้าเกี่ยวกับโครงการ

นำเมนูและหน้าเกี่ยวกับโครงการออกจากเว็บตามคอมเมนต์ล่าสุด เหลือหน้าแรก วิเคราะห์ขยะ Dashboard และประวัติ หาก session เดิมยังเลือกหน้าที่ลบไป ระบบจะกลับหน้าแรก รายละเอียดโครงการยังอยู่ในเอกสารสำหรับส่งอาจารย์ เอกสาร Proposal ฉบับก่อนปรับเมนูอาจกล่าวถึงหน้า About เดิม
