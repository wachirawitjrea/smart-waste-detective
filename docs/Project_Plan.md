# แผนพัฒนา Smart Waste Detective

สร้างต้นแบบสำหรับนักศึกษาและบุคลากร ถ่ายภาพหนึ่งวัตถุหรืออัปโหลด แล้วรับคำแนะนำและดูสถิติการวิเคราะห์

## ข้อกำหนดและการตัดสินใจ
ใช้ Streamlit + CLIP + SQLite + Plotly บนเครื่อง ไม่มี API key และไม่ส่งภาพขึ้นบริการภายนอก
ปรับแต่งด้วย prompt ensemble ภาษาอังกฤษสำหรับ 4 ประเภทและ Unknown พร้อม threshold และส่วนต่างคะแนน
ยังไม่ถือเป็น fine-tuning และ threshold เริ่มต้นยังไม่ผ่าน calibration
ไม่ทำ live video, bounding boxes, ระบบผู้ใช้หลายคน หรือการนับขยะจริง
ไฟล์ภาพผู้ใช้ไม่เก็บถาวร เก็บ SHA-256 และผลวิเคราะห์แทน

## Milestones
1. Engine: โหลดโมเดลและคำนวณผลจากภาพจริง ตรวจเส้นทาง uncertain
2. Web: Home, Upload/Camera, ผลลัพธ์, Dashboard, History, About
3. Validation: ตรวจภาพเสีย/ขนาด/ชนิดไฟล์, DB/CSV, UI startup และสคริปต์ประเมินโมเดล
4. Delivery: Proposal, diagrams, slides, script, คู่มือ และ ZIP

## เกณฑ์ยอมรับ
ไม่มีผลสุ่มหรือผลจำลองในเว็บ ทุกผลที่บันทึกมี model/prompt/threshold กำกับ
โมเดลล้มเหลวต้องแสดงข้อผิดพลาด ไม่บันทึกเป็นผลสำเร็จ
Dashboard ไม่นับข้อมูลทดสอบโดยปริยาย การล้างข้อมูลทดสอบต้องยืนยัน
เอกสารแยกสิ่งที่ทำแล้วจากแผนและการทดสอบที่ยังไม่ได้ทำ

## ประเด็นจากโจทย์อาจารย์
PDF ระบุเวลานำเสนอ 10 นาที แต่ rubric ระบุ 5 นาที จัดบทพูดสองระยะไว้
คำสั่งยอมรับ customization แต่ rubric ระดับเต็มกล่าวถึง fine-tuning จึงไม่รับประกันคะแนนจากการใช้ prompts เพียงอย่างเดียว
