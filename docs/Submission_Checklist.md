## สมาชิกกลุ่มต้องทำก่อนส่ง

กรอกชื่อและรหัสจริง ตรวจ label ของภาพด้วยคน ทดสอบกล้องบนอุปกรณ์จริง และซ้อม demo จับเวลา หากต้องการอ้างว่าช่วยลดเวลาหรือใช้งานง่าย ต้องทดลองกับคนจริงและใส่ผลที่ได้ ไม่มีการสร้างชื่อ ผลตอบรับ หรือตัวเลขแทนส่วนนี้

Canva แจ้งเครดิตหมด จึงส่งไฟล์ PPTX ที่แก้ไขได้แทน GitHub connector ไม่พบ repository ที่เข้าถึงได้ในรอบตรวจนี้ และ Teams search คืนการ์ด assignment ที่ไม่มีเนื้อหาโจทย์ครบ จึงยึด PDF ที่ผู้ใช้แนบเป็นหลัก ยังไม่มีการ push โค้ด ส่งข้อความ หรือส่งงานผ่าน Teams

## ตัวเล่มฉบับทางการล่าสุด

ใช้ `Project_Report.docx` หรือ `Project_Report.pdf` เป็นตัวเล่มหลักฉบับใหม่ 32 หน้า ขาวดำ มีบทคัดย่อ คำนำ สารบัญ 5 บท เอกสารอ้างอิง และภาคผนวก เว้นชื่อและรหัสสมาชิกไว้ 3 คน พร้อมเว้นชื่ออาจารย์ ภาคเรียน และปีการศึกษาให้เติมตามจริง

`Project_Proposal` ปรับปรุงแล้วตามภาพใหม่ 50 ภาพ ผลตรง 42 ภาพ (84%) มีสมาชิก 3 คน และภาพตัวอย่างสี 50 ภาพ ตัวเล่ม Project_Report ใช้ผลรอบแรก 44/50 (88%) แยกเป็นคนละรอบ ส่วนสไลด์เป็นไฟล์นำเสนอเดิม ควรปรับจำนวนสมาชิกและเพิ่มผลรอบใหม่ก่อนใช้ ไม่มีการสร้างผลการทดลองกับผู้ใช้ขึ้นมาแทนการทดลองจริง
